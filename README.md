# กล้าตะลุยแดนอักษร 3D

เกมผจญภัย 3 มิติ ฝึกอ่านออกเสียงภาษาไทยแนวข้อสอบ RT ชั้นประถมศึกษาปีที่ 1

น้องกล้าออกเดินทางผ่านทุ่งนา เจ้าตัวยุ่งถือป้ายคำมาขวางทาง นักเรียนต้องอ่านคำบนป้ายออกเสียงให้ถูก น้องกล้าจะยิงดาวทำลายเจ้าตัวยุ่งแล้วเดินทางต่อ ท้ายด่านมีบอสถือประโยค

## ด่านตามโครงสร้าง RT (ตอนอ่านออกเสียง)

| ด่าน | ลักษณะคำ | บอสท้ายด่าน (อ่านข้อความ) |
|---|---|---|
| 1 | สระเดี่ยว | ปูอยู่ในรู |
| 2 | คำตรงมาตรา | แมวกินปลาในจาน |
| 3 | คำมีรูปวรรณยุกต์ | ไก่อยู่ใต้บ้าน |
| 4 | คำไม่มีรูปวรรณยุกต์ | ฟันของฉันขาว |
| 5 | สระเปลี่ยนรูป ลดรูป | เด็กเลี้ยงเป็ดที่บ้าน |
| 6 | สระประสม | เสือนอนใต้ต้นไม้ |
| 7 | คำไม่ตรงมาตรา | พ่อขับรถไปตลาด |
| 8 | คำควบกล้ำ | ครูตีกลองเสียงดัง |
| 9 | อักษรนำ | หนูไปตลาดกับแม่ |

## การตรวจการอ่าน

- เปิดใน **Google Chrome** แล้วกด "กดแล้วอ่าน" ระบบจะฟังเสียงและตรวจอัตโนมัติ (ต้องอนุญาตไมโครโฟน)
- ครูหรือเพื่อนกด "อ่านถูก / ยังไม่ถูก" ตัดสินแทนได้ทุกเมื่อ เหมือนกรรมการสอบ RT
- อ่านผิดแล้วกด "ฟังเสียงตัวอย่าง" ได้ อ่านผิด 2 ครั้งข้ามไปก่อนได้
- จบด่านจะแสดงคำที่ควรฝึกเพิ่มพร้อมคำแนะนำตามลักษณะคำ

## แก้ไขคำในเกม

แก้ที่ตัวแปร `WORLDS` ในไฟล์ `index.html` (คำ 5 คำต่อด่าน และประโยคบอส)

อ้างอิงโครงสร้างจากแบบทดสอบการอ่านออกเสียง ป.1 ของสำนักทดสอบทางการศึกษา สพฐ.

พัฒนาโดย ครูวรายุ ศรีบุบผา โรงเรียนวัดเชิงท่า
