# กล้าตะลุยแดนอักษร

เกมผจญภัย 3 มิติ ฝึกอ่านออกเสียงภาษาไทยแนวข้อสอบ RT ชั้นประถมศึกษาปีที่ 1

**เล่นได้ที่:** https://godhandwarayu-beep.github.io/rt-adventure/

น้องกล้านักเวทตัวน้อยเดินทางผ่านทุ่งนาไทย กองทัพโครงกระดูกโผล่จากดินพร้อมป้ายคำ นักเรียนต้องอ่านคำบนป้ายออกเสียงให้ถูก น้องกล้าจะร่ายเวทระเบิดศัตรูแล้วเดินทางต่อ ท้ายด่านมีบอสถือประโยค

## ด่านตามโครงสร้าง RT (ตอนอ่านออกเสียง)

| ด่าน | ลักษณะคำ | บอสท้ายด่าน (อ่านข้อความ) | ช่วงเวลาในฉาก |
|---|---|---|---|
| 1 | สระเดี่ยว | ปูอยู่ในรู | เช้า |
| 2 | คำตรงมาตรา | แมวกินปลาในจาน | สาย |
| 3 | คำมีรูปวรรณยุกต์ | ไก่อยู่ใต้บ้าน | เที่ยง |
| 4 | คำไม่มีรูปวรรณยุกต์ | ฟันของฉันขาว | บ่าย |
| 5 | สระเปลี่ยนรูป ลดรูป | เด็กเลี้ยงเป็ดที่บ้าน | บ่ายแก่ |
| 6 | สระประสม | เสือนอนใต้ต้นไม้ | เย็น |
| 7 | คำไม่ตรงมาตรา | พ่อขับรถไปตลาด | ใกล้ค่ำ |
| 8 | คำควบกล้ำ | ครูตีกลองเสียงดัง | อาทิตย์อัสดง |
| 9 | อักษรนำ | หนูไปตลาดกับแม่ | สนธยา |

## การตรวจการอ่าน

- เปิดใน **Google Chrome** กดปุ่มไมโครโฟนแล้วอ่าน ระบบจะฟังเสียงและตรวจอัตโนมัติ (ต้องอนุญาตไมโครโฟน)
- ครูหรือเพื่อนกด "อ่านถูก / ยังไม่ถูก" ตัดสินแทนได้ทุกเมื่อ เหมือนกรรมการสอบ RT
- อ่านผิดแล้วกด "ฟังเสียง" ได้ อ่านผิด 2 ครั้งกด "ข้าม" ได้
- จบด่านแสดงคำที่ควรฝึกเพิ่มพร้อมคำแนะนำตามลักษณะคำ

## เครื่องช้าหรือแท็บเล็ต

ในหน้าเลือกด่านกดปุ่ม "ภาพ: สวยสุด" ให้เป็น "ภาพ: ลื่นไหล" เกมจะลดเอฟเฟกต์แสงและหญ้าลงให้เล่นได้ลื่นขึ้น

## แก้ไขคำในเกม

แก้ที่ตัวแปร `WORLDS` ในไฟล์ `index.html` (คำ 5 คำต่อด่าน และประโยคบอส)
